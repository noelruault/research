Target (pre-registered in DOD-portable-detector.md before the run):
  IoU >= 0.90 against Vision's mask on all six images = DONE.

Stack, verified on this machine:
  uv 0.11.16 -> python 3.12 -> rembg 2.0.77 + onnxruntime 1.28.0
  providers: CoreMLExecutionProvider, AzureExecutionProvider, CPUExecutionProvider
  (macOS python3 is 3.14; rembg needs 3.12, which uv supplies without touching the system)

=== THE PICK: u2net ===

It matches Vision's SPEED as well as its output -- 163-246 ms warm against Vision's ~160 ms on the
Neural Engine -- while running on ONNX Runtime, which means it also runs in a browser via
onnxruntime-web. birefnet scores highest (0.9643) but is 50x slower and 973 MB; on this corpus the
extra 1 point of IoU is not worth either.

=== SPEED IS NOT PART OF THE DoD, AND DID NOT NEED TO BE ===

The DoD deliberately excluded speed, expecting a portable model to be slower than dedicated
silicon. u2net came in at parity anyway. Recorded because the expectation was wrong in our favour,
which is the kind of thing that should be written down rather than quietly enjoyed.

=== CAVEATS ===

  - Vision's mask is the REFERENCE, NOT GROUND TRUTH. There are no human-drawn masks for these
    six images. A model scoring lower could be better; the disagreements were not adjudicated.
  - Six images, one subject type (a centred animal/object on a natural background).
  - Only three models tried, all through rembg. Not a survey.
  - onnxruntime-web performance in an actual browser is UNMEASURED. These numbers are native
    macOS with a CoreML provider available; WASM/WebGPU will differ.
