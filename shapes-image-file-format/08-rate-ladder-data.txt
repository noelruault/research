# Byte-matched rate ladder at 3840x2160: the same two coders at seven file sizes, from 20 KB to bit-exact.
#
# cwebp's quality is bisected until its file lands near the shape coder's, so at each step the only thing left to compare is the picture. Every step matches to within 2.5%.
#
# The two smallest steps need a second search. cwebp bottoms out at q0 = 85,102 B at native resolution, so a 20 KB file cannot be made by turning quality down -- it is made the way small images are actually delivered, by encoding at a lower resolution and upscaling, which still puts 3840x2160 pixels on screen. Those rows carry their encode size in the setting column and are flagged in the last column. An earlier version of this ladder pinned them to the native floor and concluded WebP "cannot go this small"; see 08-rate-floor-steelman-data.txt and report 06 #10.
#
