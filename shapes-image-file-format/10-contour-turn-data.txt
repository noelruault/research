# Contour coder, TURN CODING (contourBytes -> turnBits, code/lab/contour.go:64) at 3840x2160.

# Method: the whole measurement runs through one decoder-state machine (contourReplay) that rebuilds the
# crack graph from nothing but (junction bitmap, per-vertex direction bits, turn symbols) and asserts the
# reconstruction equals the original graph. Every context feature is read out of that decoder state, so an
# illegal tap cannot be recorded in the first place. reconstruct=true at every operating point below.
#
# Reproduction: the published contour totals are matched exactly, on two independent walks of the hd()
# scale-space (runRD + relax6 + hdMarks), before anything was changed.
#   227 -> 19079   344 -> 24106   536 -> 29674   849 -> 37518   1383 -> 45797   11121 -> 126291
#
# Commands: labx contourx <img> <maxReg>   (characterisation)
#           labx turnprice <img> <maxReg>  (side-by-side pricing, identical labels)
#           labx turnload <dir>            (re-price dumped partitions)
